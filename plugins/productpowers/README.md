# productpowers

ProductPowers agent and skills library.

## Installation

```
/plugin marketplace add tmchow/tmc-marketplace
/plugin install productpowers@tmc-marketplace
```

## Skills

- **agent-browser** - Browser automation using Vercel's `agent-browser` CLI
- **fix-code-review-feedback** - Address PR or local code review feedback with intelligent validity evaluation
